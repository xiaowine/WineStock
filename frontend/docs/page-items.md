# 物品管理页面

物品管理页拥有库存目录、新建与详情 Dialog。目录继续通过 WineStock HTTP API 查询；新建物品仍由现有
`ItemEditorDialog`、图片上传和 `POST /api/items` 完成。

## 立创资料查询

只有具备 `stock.item.manage` 权限、从物品管理打开的 `create` 模式 Dialog 显示“查询立创资料”。入库选品中复用的
快速新建 Dialog 不显示该入口，编辑已有物品也不允许通过此能力覆盖资料。

查询流程：

```text
新建物品 Dialog
  -> 查询立创资料
  -> 输入单个 C + 数字商品编号
  -> GET /api/items/lookups/lcsc/{product_code}
  -> 查询成功后显示命中摘要
     -> 不填写：草稿不变
     -> 选择属性模板（默认第一项）
     -> 覆盖填写：先应用模板、候选资料和参考价格，再异步通过 Core 读取并准备商品主图
  -> 返回外层 Dialog继续检查和保存
```

查询使用嵌套 `ModalDialog`，外层新建会话始终保持挂载。关闭、Escape 和 Android 返回只关闭最上层查询 Dialog；
查询中的关闭会中止前端请求，关闭后焦点返回“查询立创资料”。错误保留商品编号并允许原地重试。

确认覆盖后：

- 商品编号覆盖 SKU；
- 非空候选名称和描述覆盖基础字段；
- 确认态默认选择模板列表第一项，也允许改选其它模板或“不使用模板”；
- 先应用所选模板，再把候选资料覆盖到同名模板字段；模板缺少的字段创建物品私有自定义属性；
- 制造商型号、制造商、封装、数据手册和其它参数分别映射到“型号”“品牌”“封装”“数据手册”“参数”；
- 同名属性直接覆盖，缺失属性创建物品私有自定义属性；
- 空候选值不清空当前字段；
- 有效 `default_price` 覆盖参考单价；价格为空时保留当前值；
- 通过 `GET /api/items/lookups/lcsc/{product_code}/image` 读取受控图片 Blob；Core 优先返回搜索图片对应的
  `source` 高清版本并在不可用时回退原图，前端统一转换为普通待上传图片草稿并覆盖主图；
- 图片请求只在用户确认覆盖后发起；图片缺失或读取失败时保留当前主图，并使用非阻断提示；已经完成的资料、
  模板属性和价格回填不得回滚；
- 分类、单位和补货点保持不变；
- 不更新草稿 baseline，不自动保存，外层关闭继续触发现有未保存确认；
- 最终创建仍执行现有主图、SKU、模板与属性校验。

桌面 modal-actions 将查询作为左侧次要操作，取消与保存保持右侧；移动端必须检查三个按钮的实际宽度和安全区。
查询 Dialog 使用组件自有 SCSS，并在 `1440×900`、断点附近和 `390×844` 验证嵌套层级、横向溢出、长文本、
焦点、控制台和 Android 返回。
