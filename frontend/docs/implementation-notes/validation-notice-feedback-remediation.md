# 前端校验与错误 Notice 整改记录

本文记录前端表单校验、服务端错误和异步加载失败的统一反馈规则，以及本轮整改实际使用的 Notice 文案。
本文属于 `frontend` 实现记录；错误业务含义仍由所属页面、组件或 API client 负责，Notice 只拥有统一的全局呈现入口。

## 统一规则

- Notice 是错误反馈的唯一视觉文案出口。错误不得在字段下方、列表内容区或 Dialog 内容区新增可见错误行，以免改变容器高度和主要操作坐标。
- 字段错误继续通过红框、`aria-invalid`、`aria-describedby` 和首错聚焦表达；字段错误消息仅作为隐藏的无障碍说明，不重复渲染为可见文本。
- 本地校验使用 `notice.warning`，服务端错误、网络错误和异步加载失败使用 `notice.error`。
- 可恢复的加载失败在 Notice 上绑定重试回调；点击 Notice 后执行重试，不额外增加“重试”按钮或错误面板。
- 主动取消请求不生成 Notice。
- 成功 Notice 与错误 Notice 不在同一失败路径重复展示；普通操作失败保留一个错误 Notice。

## 本轮 Notice 文案

| 场景                                 | Notice 标题                                             | 详情或重试行为                                                                       |
| ------------------------------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 操作日志、入库单、出库单筛选条件非法 | `请检查筛选条件`                                        | 详情为首个字段错误；字段范围错误自动定位首个日期字段                                 |
| 复制模板名称非法                     | `请检查模板名称`                                        | 详情为“请输入新模板名称”或长度限制错误                                               |
| 立创商品编号格式非法                 | `请检查商品编号`                                        | 详情为编号格式要求；输入框保留红框和隐藏无障碍说明                                   |
| 创建用户本地校验失败                 | `请检查用户信息`                                        | 详情为首个用户名、密码或确认密码错误                                                 |
| 设置临时密码本地校验失败             | `请检查临时密码`                                        | 详情为首个密码或确认密码错误                                                         |
| 分类、库位分组、库位本地校验失败     | `请检查分类信息`、`请检查分组信息`、`请检查库位信息`    | 详情为首个字段错误                                                                   |
| 模板编辑本地校验失败                 | `请检查模板信息`                                        | 详情为首个模板字段错误；字段错误只保留无障碍隐藏说明                                 |
| 登录本地校验失败                     | `请检查登录信息`                                        | 未填写用户名、密码或其它登录输入不完整时触发；详情为首个字段错误，例如“请输入用户名” |
| 注册本地校验失败                     | `请检查注册信息`                                        | 未填写用户名、密码、确认密码或两次密码不一致时触发；详情为首个字段错误               |
| 修改密码本地校验失败                 | `请检查密码信息`                                        | 未填写当前密码、新密码、确认密码，密码过短、相同或不一致时触发；详情为首个字段错误   |
| 初始化向导服务器地址校验失败         | `请检查服务器地址`                                      | 服务器地址为空或格式不符合运行配置规则时触发；详情为首个地址校验错误                 |
| 初始化向导应用配置失败               | `应用运行配置失败`                                      | Shell 拒绝应用配置或应用配置请求失败时触发；Notice 支持点击重试                      |
| 运行设置本地校验失败                 | `请检查运行设置`                                        | 模式、服务器地址、监听地址或服务端口不符合运行配置规则时触发；详情为首个字段错误     |
| 运行设置测试远程连接校验失败         | `请检查远程连接设置`                                    | 测试远程连接前发现远程地址校验失败时触发；详情为首个字段错误                         |
| 设置当前用户账号本地校验失败         | `请检查当前用户账号`                                    | 用户名为空、密码少于 8 个字符或两次输入不一致时触发；详情为首个字段错误              |
| 运行环境初始化失败                   | `运行环境初始化失败`                                    | Shell 运行状态初始化发布错误时触发；详情为 Shell 错误                                |
| 立创资料请求失败                     | `查询立创资料失败`                                      | 详情为 API 错误；点击 Notice 重新查询                                                |
| 物品选择器目录加载失败               | `加载物品失败`                                          | 详情为 API 错误；按当前是否已有结果重试首页或下一页                                  |
| 高级筛选值加载失败                   | `加载高级筛选失败`                                      | 详情为 API 错误；点击 Notice 重试筛选值请求                                          |
| 列表展示设置保存失败                 | `保存列表展示失败`                                      | 详情为 API 错误                                                                      |
| 入库编辑器库位加载失败               | `加载库位失败`                                          | 详情为 API 错误；点击 Notice 重试库位请求                                            |
| 出库编辑器库位加载失败               | `加载库位失败`                                          | 详情补充“仍可按全部库位 FIFO 分配”                                                   |
| 出库编辑器批次加载失败               | `加载批次失败`                                          | 详情为 API 错误；点击 Notice 重试批次请求                                            |
| 出库列表首次加载失败                 | `加载出库单失败`                                        | 详情为“请检查服务连接后重试”；点击 Notice 重试                                       |
| 出库列表刷新失败                     | `刷新出库单失败`                                        | 保留已有列表；详情为“请检查服务连接后重试”；点击 Notice 重试                         |
| 出库详情加载失败                     | `加载出库单详情失败`                                    | 详情为“无法加载出库单详情，请重试。”；点击 Notice 重试                               |
| 用户管理操作失败                     | 例如 `创建用户失败`、`保存权限失败`、`设置临时密码失败` | 详情由 API 错误映射生成；服务端字段错误同时回填字段红框和隐藏说明                    |
| 服务端字段校验失败                   | 使用对应操作的错误 Notice                               | 服务端字段错误回填控件状态，同时将首个字段错误作为 Notice 详情；不新增可见错误行     |
| 登录凭据错误                         | `用户名或密码错误`                                      | 仅显示 Notice，不在登录表单显示重复文本                                              |
| 登录、注册、修改密码的其它失败       | 使用 API 或运行时错误消息                               | 仅显示 Notice；字段级校验仍通过通用字段错误语义定位                                  |

## 代码归属

- `src/notices/notice.ts`：全局 Notice 状态、去重、倒计时和点击重试回调。
- `src/composables/useFormValidation.ts`：字段注册、错误清理和首错聚焦，不负责视觉文案。
- `src/components/forms/FormField.vue`：红框、无障碍隐藏错误说明和输入后错误清理。
- 筛选、复制和查询 Dialog：负责本地规则及 Notice 标题，不能自行插入可见错误行。
- 页面和工作台：负责把异步失败转换为带详情和重试回调的 Notice，并保留稳定的已有内容。

## 验收要求

- 提交非法字段时，页面不因错误文本新增高度或推动底部操作区；首个错误字段仍可聚焦。
- Dialog、列表和工作台的加载失败不新增错误面板或字段下方可见错误；错误通过 Notice 呈现。
- 刷新失败保留已有列表或已加载批次；Notice 点击重试当前失败请求。
- 登录的“用户名或密码错误”保持仅 Notice，这是认证错误反馈基准。
- 修改 UI 后检查 `1440 × 900`、接近 `768px` 和 `390 × 844`，确认无横向溢出和新增控制台错误。
