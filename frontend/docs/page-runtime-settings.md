# 本机运行设置页面

本文记录 `/settings/runtime` 的当前实现边界。该页面是 Desktop、Android 和 Web fallback 共用的唯一运行配置 UI；平台 Shell 不再提供原生设置窗口、Activity 或对话框。

## 可用性边界

- 路由声明 `requiresAuth = false`、`requiresService = false`。
- 配置缺失、配置损坏、API 未启动、端口占用或远端断连时仍必须完整渲染。
- 其它路由缺少有效 API 地址时跳转到本页，并用 `returnTo` 保留原目标。
- 服务不可用覆盖层不得遮挡本页。

## 运行方式

页面提供三个用户可见选项：

- 本机运行：使用 `127.0.0.1`，默认端口固定为 `17890`，应用启动时必须自动运行本地服务。
- 连接远程服务：编辑完整 HTTP/HTTPS API 根地址，本设备不管理本地服务。
- 局域网服务器：本机启动服务并允许其它设备连接；是否可选由 Shell capability 决定。

`bindHost`、`port` 和 `remoteBaseUrl` 形成可编辑 DTO。自动启动不是配置项：本地模式由 Shell 固定映射为 `auto_start_server = true`，远端模式不启动本地服务。前端不读写平台配置文件，也不根据 `bindHost` 自行生成对外访问地址；实际 `apiBaseUrl`、监听地址和局域网 URL 由 Shell 快照返回。

## 交互规则

- 当前服务区只展示 Shell 发布的生命周期状态和 `/api/health` 结果，不提供手动启动、停止或重启 core 的操作；本机服务由应用 Shell 管理。
- 当前生效服务满足 `server-mode + local + running + serverMode capability` 且 Shell 返回真实
  `lanAccessUrls` 时，当前服务区显示“本机局域网地址”主入口；已登录应用壳的头像 Popover 同时提供快捷入口。
- 两个入口复用同一个“本机局域网地址” Dialog。地址逐项使用线性复制图标按钮并通过全局 Notice 反馈，
  Dialog 复用通用遮罩、焦点、Escape、关闭动画和原生返回处理。
- 前端只规范化、过滤和去重 Shell 地址；wildcard、loopback、占位符、带凭据、路径、查询或片段的值不得展示。
  快照不再满足展示条件时，入口隐藏并关闭已经打开的 Dialog。
- 端口必须是 `1..65535` 的整数；无效草稿显示“等待有效配置”，不能生成伪访问地址。
- 远端 HTTP 连接仅在非 loopback 地址上提示明文通信风险；`localhost`、`127.0.0.1` 和 `::1` 不提示远端网络风险。
- 远端“测试连接”只验证当前可达性；暂时不可连接不阻止保存格式有效的地址。
- API 地址变化、运行方式变化或开启局域网监听时必须先确认。API 地址变化后清理旧服务的内存会话并重新执行健康检查和会话初始化。
- 本地服务激活失败时保留草稿和 Shell 稳定错误，不用原生对话框替代页面反馈。

## Web fallback

普通浏览器使用 `winestock.runtime.config.v1` 保存已应用配置。没有环境地址和持久配置时返回 `unconfigured` 快照及默认 `17890` 草稿；损坏或校验失败的记录返回 `invalid` 快照，让用户在本页修复。

Web fallback 不具备真实本地服务生命周期和网卡发现能力，不得生成占位 `lanAccessUrls`。页面只能依据
快照展示服务状态和真实地址，不能从 User-Agent、全局对象名称或运行目录猜测能力。

## 响应式与验收

- 桌面为模式导航和配置区双栏，接近 `768px` 时不得产生横向溢出。
- 移动端改为单列：页头与运行方式分段 tab 粘滞在视口顶部，配置区独立滚动；底部使用预留安全区的固定操作栏，最后一个字段不得被遮挡。
- 至少验证 `1440 × 900`、接近 `768px` 和 `390 × 844`。
- 首次启动必须确认自动进入本页、默认端口为 `17890`、保存操作可用，且没有鉴权或断连覆盖层。
- 移动端滚动时运行方式 tab 不得随配置区一起滚出视口；切换三个模式后 sticky 偏移仍正确。
- 本机局域网地址 Dialog 需检查多条 IPv4/IPv6、长地址、复制反馈和地址失效关闭；桌面、断点附近与
  `390 × 844` 均不得产生页面或 Dialog 横向溢出。
