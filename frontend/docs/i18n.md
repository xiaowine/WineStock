# 前端多语言（i18n）使用规范

本文档定义 `frontend/` 的 i18n 架构与写作规则，属于前端 UI 规范的一部分。
桌面/Android 原生壳文案由各自平台目录负责（desktop `native_i18n.rs`、android `strings.xml`），不受本文档约束。

## 架构总览

- 框架：`vue-i18n` 11.x，`legacy: false`（Composition API）+ `globalInjection: true`（模板可用 `$t`）。
- 语言包：`src/i18n/locales/zh-CN/` 与 `en-US/` 按域拆分（`common`、`nav`、`error`、`validation`、
  `bridge`、`update`、`auth`、`startup`、`runtime`、`dashboard`、`items`、`stockDraft`、`orders`、
  `approvals`、`templates`、`locations`、`substitutes`、`users`、`events`、`components`、`misc`）。
  `en-US` 聚合器经 `satisfies typeof zhCN` 强制双语言键对齐，缺键在 `pnpm build` 期报错。
- 运行时：`src/i18n/index.ts` 拥有实例、语言决议（持久化偏好 → `navigator.language` → `zh-CN`）、
  持久化（`winestock.i18n.locale.v1`，跨标签页同步）与 `document.title` 同步。
- 语言偏好是前端本机偏好，**不进 Shell 运行配置**。

## 写作规则

1. **用户可见文案一律走语言包，禁止硬编码任何语言的 UI 文本**。模板 `{{ $t('key') }}`；`<script setup>` 用
   `const { t } = useI18n()`（键必须为字面量，动态键不合法）。例外仅限规则 8 的不翻译项（品牌、专名、
   URL、用户数据、语言自名）。防回退扫描只拦截中文文案字面量，**纯英文硬编码（如标题直接写 "Language"）不会被
   门禁捕获**，必须靠代码评审按本规则拦截。
2. **纯模块（非 setup）用 `translateMessageOrNull(key)`**（`import { translateMessageOrNull } from "../i18n"`），
   键不存在返回 `null`。禁止在这些模块里 import `useI18n`。
3. **错误文案**：`ApiError.message` 与 `fieldErrors` 值已在 `api/errors.ts` 构造期按
   `error.<code>` / `validation.<code>` 本地化，页面直接展示。按码映射时用
   `translateMessageOrNull(\`error.${error.code}\`) ?? error.message`，不要自建中文映射表。
4. **Shell Bridge 字段错误**：契约元素为 `{ code, message }`，页面用
   `localizeRuntimeFieldErrors(result.fieldErrors)`（`src/shell/fieldErrors.ts`）转本地化文案；
   码优先查 `bridge.*`，再查 `validation.*`，最后回退 message。
5. **路由标题**：`meta.title` 存消息键（`nav.*`），模板 `{{ $title($route.meta.title) }}`，
   script 用 `translateTitle(...)`；`document.title` 由 `installDocumentTitleSync` 自动同步。
6. **插值**：消息文本写 `{n}`，调用 `$t('key', { n: 3 })`。禁止 `字符串拼接 ${}` 拼文案。
7. **键组织**：键按域文件归属；通用词（保存/取消/删除/关闭/确认）优先复用 `common.*`；
   后端码类键必须与码逐字对应（snake_case），例如 `error.sku_taken`、`validation.invalid_ip`、
   `update.update_manifest_invalid`、`bridge.port_in_use`。
8. **不翻译**：品牌 WineStock、专名（LCSC/立创、WebView）、URL、用户数据、后端业务数据。
9. **日志与诊断**：`console.*`、异常类 message 等开发者诊断用英文，不调用 t()（扫描豁免这些是
   中文注释；诊断串本身不要写中文）。
10. **中文注释保留**：代码注释按仓库规范继续使用中文；防回退扫描只检查字符串/模板文本。

## 防回退扫描

`pnpm test:i18n-scan`（`tests/i18nScan.test.mjs`）是 i18n 门禁，两项检查：

1. 语言资源目录（`src/i18n/locales/`）与生成契约（`src/api/generated/`）以外的 `.vue`/`.ts` 源码，
   剥离注释后不允许出现中文文案字面量。注意：该检查只捕获中文，纯英文硬编码依赖评审按写作规则 1 拦截。
2. core 错误码注册表（`core/src/http/error_codes.rs`）与 shared garde 码
   （`shared/src/garde_code.rs`）的每个码必须在 `zh-CN/error.ts` / `validation.ts` 有键覆盖。

新增后端错误码时：先在 core 注册表登记，再在 `zh-CN/error.ts` + `en-US/error.ts` 同步加键，
最后跑 `pnpm test:i18n-scan` 确认。

## 新增语言

在 `src/i18n/model.ts` 的 `SUPPORTED_LOCALES` 增加语言代码；语言包新增目录并在 `index.ts`
聚合器注册；`fallbackLocale` 保持 `zh-CN`。语言自名（如 `common.languageDe`）在两语言包都保持原文。
