# WineStock 品牌资源

本目录拥有跨平台品牌母版，不属于 frontend、Android 或未来 Desktop Shell 的局部资源。

- `winestock-mark.svg`：透明背景的 Indexed Cube 标志母版；用于界面品牌标志和单色派生。
- `winestock-icon.svg`：酒红背景的应用图标母版；用于 favicon 和平台图标预览。

母版采用 `108 x 108` 视口。各平台可以按自身遮罩、安全区和资源格式生成派生文件，但必须保持箱体三面及侧面索引标签的几何关系，不得在平台目录中重新设计近似版本。

主色为 `#6F2A36`，反白色为 `#F4F5F7`；深色主题上的透明标志可以使用 `#D48B98`。图标不使用字体、描边或渐变。
