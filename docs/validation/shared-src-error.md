# `shared/src/error.rs`

本文件定义共享配置解析错误。

## `ConfigParseError`

| 变体           | 限制或含义                              |
|--------------|------------------------------------|
| `Json`       | JSON 语法、字段类型或未知字段错误                |
| `Validation` | JSON 已能反序列化，但字段值不满足 `garde` 静态字段约束 |

该错误只描述平台无关配置解析结果；配置文件位置、默认配置创建和启动策略由平台 shell 处理。
