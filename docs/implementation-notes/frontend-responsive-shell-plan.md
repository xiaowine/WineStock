# 前端响应式应用壳演进记录

本文只记录前端页面框架讨论过程中的关键演进。
当前实施准则以 `docs/frontend/page-framework.md` 为准。

## 当前结论

当前只确认了页面显示框架和响应式 Shell 结构。
尚未确认任何具体业务页面内容结构。

已经确认：

- 前端保持一套共享源码。
- 暂时只实现浅色主视觉。
- 桌面端使用顶部栏、左侧常驻导航区域和右侧内容区域。
- 移动端使用顶部栏、单列内容区域和左侧临时导航 Drawer。
- 顶部栏不承担页面跳转。
- 当前原型里的导航项、指标、库存列表、服务地址、按钮和操作都是预览占位。

尚未确认：

- 页面数量、路由路径、模块命名和排序。
- 每个页面的字段、指标、列表、表格、筛选项和操作。
- 顶部栏、左侧导航区域和移动端 Drawer 的最终内容。
- 库存、用户、库位等业务页面的最终交互流程。

## 讨论演进

早期讨论过桌面端使用浮层 menu，并在移动端使用底部导航或底部 Sheet。
后续已调整为：

- 桌面端不使用浮层 menu，不使用压黑遮罩。
- 桌面端使用类似 WinUI3 NavigationView 的左右分栏。
- 左侧导航区域和右侧内容区域是同级区域，不做卡片套卡片。
- 移动端不保留底部常驻导航栏。
- 移动端模块导航使用左侧 Drawer。
- 页面级筛选、排序等操作后续再按页面设计 Sheet、全屏面板或其它容器。
