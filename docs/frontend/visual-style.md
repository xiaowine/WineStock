# 前端视觉风格

本文记录当前前端原型采用的视觉方向。
本文只确认视觉语言，不确认具体业务页面内容。

## 方向

当前风格定为中性业务工具风格。
它不直接采用 WinUI、Material 3 或某个现成后台模板。

目标气质：

- 安静。
- 清晰。
- 长时间使用不疲劳。
- 桌面端适合表格和高密度信息。
- 移动端触控友好，但不变成消费级 App。
- 使用浅色控制台外壳，靠分隔线、选中条和密度建立产品识别。

## 参考原则

可以参考成熟产品的共性，而不是照搬某个设计系统：

- Linear、GitHub、Vercel、Stripe Dashboard 的克制中性色。
- 管理工具常见的分隔线、工具栏、表格和列表密度。
- 移动端保留常见 Drawer、Sheet、全屏面板交互，但视觉 token 与桌面一致。

不采用：

- Material 3 默认大圆角、高色彩和消费 App 气质。
- WinUI 默认外观。
- Ant Design 默认后台模板感。
- 营销页式大留白、渐变、装饰图形和漂浮卡片。

## 色彩

当前只做浅色主题。

规则：

- 页面背景使用低对比浅灰。
- 内容区域使用白色或近白。
- 导航区域使用浅灰底和右边线，不做卡片。
- 导航选中态使用浅色行、细 accent 条和轻边框，不使用整块深色导航。
- 主色使用低饱和酒红，只用于主按钮、选中态和少量强调。
- 状态色低饱和，避免大面积彩色块。
- 不使用动态取色或多主题色。

## 层级

优先使用：

- 分隔线。
- 背景差。
- 字号和字重。
- 间距。

谨慎使用：

- 阴影，只用于 Drawer、Dialog、Popover 等浮层。
- 卡片，只用于真正重复项目或需要独立框定的内容。

当前页面框架不使用卡片套卡片。

## 圆角和密度

圆角保持克制：

- 小控件优先 `4px`。
- 普通容器优先 `6px`。
- 大容器最多 `8px`。

桌面端：

- 信息密度偏紧凑。
- 表格和工具栏优先。
- 不做大块卡片列表。

移动端：

- 触控区域比桌面更高。
- 主内容仍保持同一套颜色、边框、字体和状态样式。
- 移动端列表可以单列展示，但不做过度圆润的大卡片。

## 字体和图标

- 使用系统字体。
- 不引入设计感字体。
- 功能图标统一使用单色线性语言，默认 `18px`、圆端点和圆转角，并继承所在控件的文字颜色。
- 当前应用导航使用受控的内置线性图标，不复用脚手架遗留的社交图标，也不混用 emoji、填充图标或多彩图标。
- 新图标必须先确认语义、尺寸、线宽和状态色与现有导航一致，再加入共享组件或后续统一图标层。

## 动效

动效属于同一套中性业务工具视觉语言，目标是帮助用户理解浮层从哪里出现、状态何时完成，而不是制造装饰感。

统一规则：

- 快速反馈使用 `120ms`，浮层进入、离开和列表重排使用 `160ms`。
- 所有组件必须使用 `tokens.css` 中的 motion 变量，不在组件内自行硬编码时长或缓动曲线。
- 标准缓动统一使用 `cubic-bezier(0.2, 0, 0, 1)`，保持快速响应并平稳结束。
- 进入时使用透明度配合小幅定向位移；位移方向应体现触发位置或浮层来源。
- 锚定在控件旁的 Popover 使用 `6px` 位移，可配合最多 `0.98` 的轻微缩放。
- 屏幕边缘出现的 Notice 可使用 `18px` 位移，但时长和缓动必须与其它浮层一致。
- Drawer、Dialog、Sheet 后续增加动画时也必须复用相同 token：遮罩只改变透明度，内容只做来源方向位移，不使用另一套动画语言。
- 关闭动画与打开动画保持同一方向逻辑，不使用弹跳、旋转、明显过冲或大幅缩放。
- 系统启用 `prefers-reduced-motion: reduce` 时，将非必要动画压缩为近乎即时的状态切换。

当前 motion token：

- `--motion-duration-fast`
- `--motion-duration-standard`
- `--motion-ease-standard`
- `--motion-distance-small`
- `--motion-distance-medium`

## 当前源码对应

- `frontend/src/styles/tokens.css`：当前颜色、尺寸和统一 motion token。
- `frontend/src/styles/layout.css`：桌面和移动端应用壳布局。
- `frontend/src/styles/components.css`：当前原型组件外观。
- `frontend/src/styles/base.css`：基础渲染规则和减少动态效果适配。

当前原型中的业务文字、数字、按钮和列表都是占位内容，不属于视觉风格结论。
