# `shared/src/config_file.rs`

本文件定义平台无关的 JSON 启动配置文件加载与缺失文件初始化。

## `load_or_create_json_config()`

- 配置路径和默认 `AppConfig` 必须由平台 shell 明确传入。
- 已有文件只读取、解析和校验，不会被默认配置覆盖。
- 只有读取错误为 `NotFound` 时才创建默认文件，其他 IO 错误直接返回。
- 创建父目录后，使用格式化 JSON 和末尾换行写入默认配置。
- 使用非覆盖式文件创建；如果文件在读取和创建之间出现，则返回写入错误，不覆盖该文件。
- 返回值通过 `created_default` 告知平台 shell 本次是否创建了文件。

本模块不决定配置文件应位于可执行文件、应用数据目录还是其他平台路径，也不解析存储相对路径或决定服务启动模式。
